# 池塘水生植物觀察站

四年級上學期自然科 **第二單元「水生生物與環境」** 的 360° 互動網頁。學生站在池塘中央的木棧道上環顧四周，也可以潛入水下觀察根長在哪裡，藉此認識四類水生植物：

- **沉水性**：水蘊草、苦草
- **挺水性**：荷花、香蒲
- **浮葉性**：睡蓮、臺灣萍蓬草
- **漂浮性**：布袋蓮、大萍、浮萍

## 功能

- 拖曳 360° 環顧，滾輪或雙指縮放
- 「水面上／潛入水下」兩種視角
- 水位滑桿：觀察葉柄伸展或彎曲、漂浮植物隨水面升降
- 探索模式：點圖釘看植物卡片（根、葉、花的位置，適應特徵，觀察任務）
- 分類挑戰模式：辨認 9 株「神秘植物」，答錯有提示

## 使用

直接開啟網頁即可，不需要安裝。單一 HTML 檔，使用 Three.js r128（cdnjs）。
