# 水生生物 360° 觀察站｜AI 全景版

四年級上學期自然科 **第二單元「水生生物與環境」** 的 360° 互動網頁。此分支使用兩張 AI 生成的 2:1 球形全景圖，讓學生環視池塘水面與水下環境，觀察蓋斑鬥魚及四類水生植物：

- **沉水性**：水蘊草、苦草
- **挺水性**：荷花、香蒲
- **浮葉性**：睡蓮、臺灣萍蓬草
- **漂浮性**：布袋蓮、大萍、浮萍

## 功能

- 拖曳 360° 環顧，滾輪或雙指縮放
- 「水面上／潛入水下」兩種視角
- 以寫實 AI 全景呈現完整池塘環境，不再拼貼課本照片
- 探索模式：點圖釘查看課本植物照片與觀察卡片
- 分類挑戰模式：辨認 9 株「神秘植物」，答錯有提示
- 座標校正工具：協助教師微調全景熱點

## 使用

直接開啟 `index.html` 即可，不需要安裝。全景圖片已內嵌於單一 HTML 檔，使用 Three.js r128（cdnjs）。

原始版本保留在 `main` 分支；本版本位於 `ai-panorama` 分支。
